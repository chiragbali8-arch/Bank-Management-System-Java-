# Bank Management System

A console-based banking application developed in Java. This project demonstrates Object-Oriented Programming (OOP) concepts and allows users to perform basic banking operations such as creating accounts, updating account details, checking balances, depositing money, and closing accounts.

## Features

* Create New Account
* Display Account Details
* Update Account Information
* Close Account
* Check Account Balance
* Deposit Money
* Automatic Account Number Generation

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* Scanner Class

## Purpose

This project was created as a learning project to improve Java programming skills and understand real-world implementation of object-oriented concepts.
